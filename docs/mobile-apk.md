# Мобильная сборка (Android APK через Capacitor)

Десктоп собирается через Electron, мобилка — через **Capacitor 7**:
тот же React-билд (`dist/`) заворачивается в нативное Android-приложение
(`android/` уже добавлен в репозиторий, `appId: uz.posvk.posterminal`).

Бэкенд на телефоне **локальный**: отдельной Node-службы в APK нет,
все данные лежат на устройстве (как у десктопа), а общая синхронизация
идёт через **cabinet API** (интернет). Связка master/slave по локальной
сети на мобайле отключена — каждый телефон работает как автономный
терминал (роль всегда `neutral`).

Печать — по **классическому Bluetooth (SPP)**, тот же флоу что в
`posvk_mobile` (Flutter): `print_bluetooth_thermal` ↔ `BluetoothSerial`
(`connect → write → disconnect`), текст чека транслитерируется в латиницу
(карта из `bluetooth_printer_service.dart`), поэтому ESC/POS-задание —
чистый ASCII и печатается даже на дешёвых 58мм принтерах без кириллических
кодовых страниц.

## Требования

- Node 18+, JDK 17, Android SDK (или просто **Android Studio**)
- Принтер: термопринтер 58/80мм с классическим Bluetooth (SPP)

## Принтер: сопряжение

1. В настройках Bluetooth **телефона** выполните сопряжение с принтером
   (PIN обычно `0000` или `1234`).
2. Откройте в приложении **Настройки → Настройка печати** — на мобайле
   вместо «Терминал/Принтер» будет список **Bluetooth-принтер**,
   кнопки **Обновить** и **Тест** (печатает тестовый чек).
3. Выберите принтер отдельно для кассира / кухни / официанта,
   формат бумаги 58/80 — как обычно.

При первом сканировании Android 12+ спросит разрешение
«Устройства рядом» (`BLUETOOTH_SCAN` / `BLUETOOTH_CONNECT`) — разрешите.

## Сканер кодов (камера)

Кнопка сканера в поиске Меню и QR-кнопка в окне Маркировки на мобайле
открывают камеру (ML Kit, `@capacitor-mlkit/barcode-scanning`):
EAN-13/8, UPC, Code 128/39/93, ITF, Codabar, **DataMatrix, QR** —
те же форматы что в `posvk_mobile`. Нужны Google Play Services
(модуль сканера докачивается сам) и разрешение камеры.
На десктопе кнопка по-прежнему работает со сканером-«клавиатурой»
через USB (wedge-режим).

## Сборка APK

```bash
npm install
npm run mobile:sync    # web-билд + синхронизация в android/
npm run mobile:open    # открыть проект в Android Studio
```

Дальше в Android Studio: **Build → Build App Bundle(s) / APK(s) →
Build APK(s)**. Debug-APK ставится напрямую на телефон.
Для релиза подпишите ключом (**Build → Generate Signed Bundle / APK**).

Через CLI (нужны SDK + Gradle):

```bash
cd android
./gradlew assembleDebug   # android/app/build/outputs/apk/debug/app-debug.apk
```

## Скрипты

| Команда | Что делает |
|---|---|
| `npm run mobile:sync` | `vite build` + `cap sync android` |
| `npm run mobile:android:add` | пересоздать `android/` (обычно не нужно) |
| `npm run mobile:open` | открыть в Android Studio |

## Ограничения мобайла

- Нет локального `backend/server` — все `/api/*` недоступны, приложение
  сразу работает с локальным хранилищем (старт без ожидания бэкенда).
- Нет сети терминалов (master/slave): принтеры только Bluetooth,
  «Сеть терминалов» на телефоне не используется.
- Иконка приложения — из `assets/logo.png` (генерация:
  `npx capacitor-assets generate --android --assetPath assets ...`).
- USB считыватель ФМ (Feitian, VID 2414): в манифест добавлен
  `device_filter.xml` + `USB_DEVICE_ATTACHED`, поэтому при подключении
  Android предлагает открыть приложение. Но **прямые операции ФМ**
  (регистрация чеков, Z-отчёты через APDU-стек как в `posvk_mobile` —
  ~100 Java-файлов + нативная `.so`) в мобайл пока не портированы:
  чеки уходят через очередь cabinet API при появлении интернета
  (как десктоп офлайн), на экране ФМ показано предупреждение.
- iOS не поддерживается для SPP-принтеров (Apple не даёт API
  классического Bluetooth) — только Android.

## Если что-то пошло не так

- Список принтеров пуст → проверьте сопряжение в настройках Bluetooth
  и разрешение «Устройства рядом» для приложения.
- «Не удалось подключиться» → выключите/включите принтер, убедитесь что
  он не подключён к другому устройству (SPP — одно соединение).
- Кракозябры в чеке → шлите скрин тестового чека: весь текст должен быть
  латиницей после транслитерации.
- `cap sync` ругается на плагин → `npx cap update android`.
